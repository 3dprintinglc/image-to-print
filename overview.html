Two ways to turn an image into a 3D print

LLMs can take a photo or sketch and produce a printable file. The right route depends on one question about the object. Below is the decision, the full flow for each path, and which one fits common projects.

Path A. CAD code

Exact dimensions

A vision LLM reads the image and writes a parametric CAD script. The script is the model, so every measurement stays editable.

Photo, sketch, or drawing of the part plus key measurements

Build solid

Script runs on a real CAD kernel to produce clean geometry

OpenCascade

Review and tweak

Preview, then ask the LLM to adjust a value and rerun

Save as a print file, or STEP for other CAD tools

STL3MFSTEP
7

Slice and print

Slicer turns the file into printer instructions

OrcaSlicerPrusaSlicerCura

Output is watertight by design, so it rarely needs repair. Step 5 is the loop where most of the value lives. Changing a wall thickness is one sentence to the LLM.

Path B. Image to mesh

Organic shapes

An image-to-3D model generates a mesh from a single photo. An LLM agent then drives Blender to clean it up and make it printable.

Experimental
